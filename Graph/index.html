Graph

Graphs

Graphs used to model real-world connections like social networks, road maps, web pages, flight routes, and much more.

1. Graph

A Graph is a non-linear data structure that represents relationships between objects.

It consists of:

  • Vertices (Nodes): The entities or points
  • Edges: The connections between those points

Visual Example:

A ---- B
|      |
C ---- D
  • Vertices: A, B, C, D
  • Edges: (A-B), (A-C), (B-D), (C-D)

2. Types of Graphs

1. Undirected Graph

Edges have no direction — you can travel both ways.

Example:

A -- B

This means A is connected to B and B is connected to A.

2. Directed Graph

Edges have a specific direction.

Example:

A → B

Here, you can go from A to B, but not from B to A (unless there’s another edge).

3. Weighted Graph

Edges carry a weight (cost, distance, time, etc.).

Example:

A --5-- B
B --3-- C

3. Graph Representation in Python

There are two popular ways to represent a graph:

1. Adjacency Matrix

A 2D list (matrix) where matrix[i][j] = 1 means there is an edge between node i and node j.

Example Graph:

A -- B
A -- C
B -- D
C -- D

Adjacency Matrix:

n = 4  # number of vertices
graph = [
    [0, 1, 1, 0],  # A
    [1, 0, 0, 1],  # B
    [1, 0, 0, 1],  # C
    [0, 1, 1, 0]   # D
]

# Check if edge exists between A (0) and B (1)
if graph[0][1] == 1:
    print("Edge exists between A and B")

Pros: Fast edge lookup (O(1))

Cons: Uses more space O(V²)

2. Adjacency List (Most Commonly Used)

Each node points to a list of its neighboring nodes. This is more memory efficient and easier to work with in most cases.

graph = {
    'A': ['B', 'C'],
    'B': ['A', 'D'],
    'C': ['A', 'D'],
    'D': ['B', 'C']
}

print(graph['A'])  # Output: ['B', 'C']

4. Building a Graph – Adding Edges

Here’s a clean way to build an undirected graph dynamically:

graph = {}

def add_edge(u, v):
    if u not in graph:
        graph[u] = []
    if v not in graph:
        graph[v] = []

    graph[u].append(v)
    graph[v].append(u)   # remove this line for directed graph

add_edge('A', 'B')
add_edge('A', 'C')
add_edge('B', 'D')
add_edge('C', 'D')

print(graph)

Output:

{'A': ['B', 'C'], 'B': ['A', 'D'], 'C': ['A', 'D'], 'D': ['B', 'C']}

5. Graph Traversal

Traversal means visiting all the nodes in the graph. The two fundamental algorithms are DFS and BFS.

6. DFS (Depth First Search)

DFS goes as deep as possible along one branch before backtracking.

Example Graph:

    A
   / \\
  B   C
  |
  D

DFS Traversal Order: A → B → D → C

Recursive DFS Implementation:

graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': [],
    'D': []
}

visited = set()

def dfs(node):
    if node not in visited:
        print(node, end=" ")
        visited.add(node)

        for neighbor in graph[node]:
            dfs(neighbor)

print("DFS Traversal:")
dfs('A')

Output: A B D C

7. BFS (Breadth First Search)

BFS visits nodes level by level using a queue.

BFS Traversal Order: A → B → C → D

BFS Implementation using Queue:

from collections import deque

graph = {
    'A': ['B', 'C'],
    'B': ['D'],
    'C': [],
    'D': []
}

def bfs(start):
    visited = set()
    queue = deque([start])
    visited.add(start)

    while queue:
        node = queue.popleft()
        print(node, end=" ")

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

print("BFS Traversal:")
bfs('A')

Output: A B C D

8. Cycle Detection in Undirected Graph (Using DFS)

graph = {
    'A': ['B'],
    'B': ['A', 'C'],
    'C': ['B']
}

visited = set()

def has_cycle(node, parent):
    visited.add(node)

    for neighbor in graph[node]:
        if neighbor not in visited:
            if has_cycle(neighbor, node):
                return True
        elif neighbor != parent:
            return True  # back edge found
    return False

print("Has Cycle:", has_cycle('A', None))

9. Finding Connected Components

graph = {
    'A': ['B'],
    'B': ['A'],
    'C': ['D'],
    'D': ['C']
}

visited = set()

def dfs(node):
    visited.add(node)
    print(node, end=" ")

    for neighbor in graph[node]:
        if neighbor not in visited:
            dfs(neighbor)

print("Connected Components:")
for node in graph:
    if node not in visited:
        print("\\nComponent:", end=" ")
        dfs(node)
