DP

1. Optimal Substructure

Definition

A problem exhibits optimal substructure when the optimal solution of the overall problem can be constructed from optimal solutions of its subproblems.

This property is the foundation of Dynamic Programming.

Mathematical Idea

If:

Optimal(S) = combine(Optimal(S1), Optimal(S2), ...)

Then the problem has optimal substructure.

Example: Fibonacci

The recurrence relation:

F(n) = F(n-1) + F(n-2)

The optimal value of F(n) depends on optimal values of F(n-1) and F(n-2).

Python Implementation

def fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

print(fib(6))

Time Complexity

O(2^n)

Because the recursion tree grows exponentially.

Another Classic Example

Shortest Path Problem

Algorithms like:

  • Dijkstra
  • Bellman-Ford

work because shortest paths contain shortest subpaths.

Example:

A → B → C → D

If the shortest path from A to D goes through C, then the path A → C must also be the shortest.

2. Overlapping Subproblems

Definition

A problem has overlapping subproblems if the same subproblems are solved repeatedly during recursion.

Dynamic Programming avoids recomputing them.

Example: Fibonacci Recursion Tree

fib(5)
 ├── fib(4)
 │    ├── fib(3)
 │    │    ├── fib(2)
 │    │    └── fib(1)
 │    └── fib(2)
 └── fib(3)

Here:

fib(3)
fib(2)

are solved multiple times.

Complexity Without DP

Time = O(2^n)

3. Memoization (Top-Down Dynamic Programming)

Definition

Memoization is a top-down dynamic programming technique where recursion is used and results of solved subproblems are stored in memory.

When the same subproblem appears again, the stored value is reused.

Algorithm Steps

  1. Start with the main problem.
  1. Recursively divide into subproblems.
  1. Store results in a cache (dictionary/array).
  1. If the subproblem is already solved, return stored result.

Python Implementation

memo = {}

def fib(n):

    if n in memo:
        return memo[n]

    if n <= 1:
        return n

    memo[n] = fib(n-1) + fib(n-2)

    return memo[n]


print(fib(10))

Complexity

Time Complexity: O(n)
Space Complexity: O(n)

Because each subproblem is solved only once.

4. Tabulation (Bottom-Up Dynamic Programming)

Definition

Tabulation is a bottom-up DP approach where we solve the smallest subproblems first and build up to the final solution.

Instead of recursion, we use iteration and a table (array).

Algorithm Steps

  1. Define DP table
  1. Initialize base cases
  1. Fill table iteratively
  1. Return final result

Python Example

def fib(n):

    dp = [0] * (n + 1)

    if n > 0:
        dp[1] = 1

    for i in range(2, n + 1):
        dp[i] = dp[i-1] + dp[i-2]

    return dp[n]


print(fib(10))

DP Table Example

Index: 0 1 2 3 4 5
Value: 0 1 1 2 3 5

Complexity

Time: O(n)
Space: O(n)

6. Longest Increasing Subsequence (LIS)

Problem Definition

Given an array of integers:

arr = [10,22,9,33,21,50,41,60]

Find the length of the longest subsequence where elements are strictly increasing.

Subsequence example:

10 → 22 → 33 → 50 → 60

Length:

5

7. LIS Using Dynamic Programming

Idea

For each element i:

LIS(i) = 1 + max(LIS(j))

Where

j < i
arr[j] < arr[i]

Python Implementation

def lis(arr):

    n = len(arr)

    dp = [1] * n

    for i in range(1, n):
        for j in range(i):

            if arr[i] > arr[j]:
                dp[i] = max(dp[i], dp[j] + 1)

    return max(dp)


arr = [10,22,9,33,21,50,41,60]

print(lis(arr))

Step Example

Array

[10,22,9,33]

DP Table

Index : 0 1 2 3
Value :10 22 9 33
DP    : 1 2 1 3

Explanation

10 → length 1
22 → 10 < 22 → length 2
9 → reset → 1
33 → 10,22 → length 3

Complexity

Time Complexity: O(n²)
Space Complexity: O(n)

8. Optimized LIS (Advanced DSA)

Using Binary Search + Greedy

def lis(arr):

    tails = []

    for num in arr:

        left = 0
        right = len(tails)

        # binary search
        while left < right:
            mid = (left + right) // 2

            if tails[mid] < num:
                left = mid + 1
            else:
                right = mid

        # update tails
        if left == len(tails):
            tails.append(num)
        else:
            tails[left] = num

    return len(tails)


arr = [10,22,9,33,21,50,41,60]

print(lis(arr))
Time Complexity: O(n log n)
