1. Adjacency List

An Adjacency List is one of the most popular and memory-efficient ways to represent a graph in computer science. Instead of using a full matrix, we store each node and a list of its directly connected neighbors along with the edge weights (in case of a weighted graph).

This representation is especially useful for sparse graphs where the number of edges is much less than the maximum possible (V²).

Example Graph:

0 → 1 (4)
0 → 2 (1)
1 → 3 (1)
2 → 1 (2)
2 → 3 (5)
3 → 4 (3)

Adjacency List Representation:

graph = {
    0: [(1,4), (2,1)],
    1: [(3,1)],
    2: [(1,2), (3,5)],
    3: [(4,3)],
    4: []
}

Format:

node : [(neighbor, weight), ...]

Example:

0 : (1,4) (2,1)

2. Dijkstra’s Algorithm (Using Adjacency List)

Dijkstra’s Algorithm is a classic greedy algorithm used to find the shortest path from a single source vertex to all other vertices in a graph with non-negative edge weights.

It works on the principle of always expanding the least-cost path first. The algorithm maintains a distance array and repeatedly selects the unvisited node with the smallest known distance, then tries to improve (relax) the distances to its neighbors.

Because it always processes nodes in increasing order of distance, once a node is marked as visited, its shortest distance is guaranteed to be finalized.

Python Implementation:

def dijkstra(graph, start):

    INF = 999999
    n = len(graph)

    dist = [INF]*n
    visited = [False]*n

    dist[start] = 0

    for _ in range(n):

        # find minimum distance vertex
        min_dist = INF
        u = -1

        for i in range(n):
            if not visited[i] and dist[i] < min_dist:
                min_dist = dist[i]
                u = i

        visited[u] = True

        # relax neighbors
        for v,w in graph[u]:
            if not visited[v] and dist[u] + w < dist[v]:
                dist[v] = dist[u] + w

    return dist


graph = {
    0: [(1,4),(2,1)],
    1: [(3,1)],
    2: [(1,2),(3,5)],
    3: [(4,3)],
    4: []
}

print(dijkstra(graph, 0))

Output:

[0, 3, 1, 4, 7]

Meaning (Shortest distances from node 0):

  • 0 → 1 = 3
  • 0 → 2 = 1
  • 0 → 3 = 4
  • 0 → 4 = 7

3. Bellman-Ford Algorithm (Using Adjacency List)

Theory:

The Bellman-Ford Algorithm is a dynamic programming-based algorithm that computes shortest paths from a single source vertex to all other vertices in a weighted graph.

Unlike Dijkstra’s, Bellman-Ford can handle graphs with negative edge weights and can also detect the presence of negative weight cycles (which would make shortest paths undefined).

It works by relaxing all the edges |V|–1 times. The idea is that after |V|–1 iterations, the shortest path to every vertex (if it exists) will have been found, because the shortest path can have at most |V|–1 edges.

Python Implementation:

def bellman_ford(graph, vertices, source):

    INF = 999999
    dist = [INF]*vertices
    dist[source] = 0

    # relax edges V-1 times
    for _ in range(vertices-1):
        for u in graph:
            for v,w in graph[u]:

                if dist[u] != INF and dist[u] + w < dist[v]:
                    dist[v] = dist[u] + w

    # detect negative cycle
    for u in graph:
        for v,w in graph[u]:

            if dist[u] != INF and dist[u] + w < dist[v]:
                print("Negative cycle detected")
                return

    return dist


graph = {
    0: [(1,4),(2,5)],
    1: [(2,-3)],
    2: [(3,4)],
    3: []
}

print(bellman_ford(graph, 4, 0))

Output:

[0, 4, 1, 5]

1. Minimum Spanning Tree (MST)

Theory

For a connected weighted undirected graph, a Minimum Spanning Tree is a subset of edges that:

  • Connects all vertices
  • Has no cycles
  • Has minimum total weight

If graph has V vertices, MST will have V − 1 edges.

Example Graph

    2
A ------ B
| \      |
6  3     5
|    \   |
C ------ D
     4

Goal → choose edges with minimum total cost connecting all nodes.

2. Prim's Algorithm

Idea

Prim’s algorithm grows the MST from a starting vertex.

Steps:

  1. Start from any node.
  1. Add the smallest edge connecting visited → unvisited node.
  1. Repeat until all nodes are visited.

Time Complexity

  • O(V²) without heap
  • O(E log V) with heap

Prim’s Algorithm (Python)

def prim(graph, n):
    visited = [False] * n
    visited[0] = True
    edges = []

    total_cost = 0

    for _ in range(n - 1):
        min_edge = (None, None, float('inf'))

        for u in range(n):
            if visited[u]:
                for v, w in graph[u]:
                    if not visited[v] and w < min_edge[2]:
                        min_edge = (u, v, w)

        u, v, w = min_edge
        visited[v] = True
        edges.append((u, v, w))
        total_cost += w

    return edges, total_cost


graph = {
0: [(1,2),(2,6),(3,3)],
1: [(0,2),(3,5)],
2: [(0,6),(3,4)],
3: [(0,3),(1,5),(2,4)]
}

edges, cost = prim(graph,4)

print("MST edges:", edges)
print("Total cost:", cost)

Output

MST edges: [(0,1,2), (0,3,3), (3,2,4)]
Total cost: 9

3. Kruskal's Algorithm

Idea

Instead of growing from a vertex, Kruskal sorts edges by weight.

Steps:

  1. Sort edges by smallest weight
  1. Add edge if it does not form a cycle
  1. Stop when V−1 edges selected

To detect cycles we use Union-Find (Disjoint Set).

4. Union-Find (Disjoint Set)

Purpose

Efficiently checks whether two nodes belong to the same component.

Operations:

OperationMeaning
Find(x)Find parent/root
Union(x,y)Merge two sets

Optimizations:

  • Path compression
  • Union by rank

Union-Find Implementation

class DisjointSet:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0]*n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        rootX = self.find(x)
        rootY = self.find(y)

        if rootX == rootY:
            return False

        if self.rank[rootX] < self.rank[rootY]:
            self.parent[rootX] = rootY
        elif self.rank[rootX] > self.rank[rootY]:
            self.parent[rootY] = rootX
        else:
            self.parent[rootY] = rootX
            self.rank[rootX] += 1

        return True

5. Kruskal Algorithm (Python)

def kruskal(n, edges):
    edges.sort(key=lambda x: x[2])

    ds = DisjointSet(n)

    mst = []
    cost = 0

    for u,v,w in edges:
        if ds.union(u,v):
            mst.append((u,v,w))
            cost += w

    return mst, cost


edges = [
(0,1,2),
(0,2,6),
(0,3,3),
(1,3,5),
(2,3,4)
]

mst, cost = kruskal(4, edges)

print("MST:", mst)
print("Total cost:", cost)

Output

MST: [(0,1,2), (0,3,3), (2,3,4)]
Total cost: 9
