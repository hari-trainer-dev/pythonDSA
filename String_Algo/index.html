String Algo

String Algorithms in DSA

1. String Hashing

Idea:

String hashing is a technique to convert a string into a single integer (called a hash value). This makes comparing strings or substrings extremely fast.

It’s heavily used in pattern matching algorithms like Rabin-Karp and for quickly checking if two strings (or substrings) are equal.

How it works (Polynomial Rolling Hash):

We treat each character as a digit in a base-p number system and compute:

hash(s) = (s[0] * p⁰ + s[1] * p¹ + s[2] * p² + …) % mod

where p is a small prime (usually 31 or 53) and mod is a large prime (like 10⁹+7) to avoid overflow.

Python Implementation:

def compute_hash(s):
    p = 31
    mod = 10**9 + 7
    hash_value = 0
    power = 1

    for ch in s:
        hash_value = (hash_value + (ord(ch) - ord('a') + 1) * power) % mod
        power = (power * p) % mod

    return hash_value


print(compute_hash("hello"))  # Different strings give different hashes
print(compute_hash("world"))

2. KMP Algorithm (Knuth-Morris-Pratt) – Pattern Matching

Idea:

The KMP algorithm efficiently searches for a pattern in a text without re-checking characters that we already know won’t match again. It uses an LPS (Longest Prefix Suffix) array that tells us how much we can skip when a mismatch occurs.

Time Complexity: O(n + m) — where n is text length and m is pattern length.

Python Implementation:

def build_lps(pattern):
    lps = [0] * len(pattern)
    j = 0
    i = 1
    while i < len(pattern):
        if pattern[i] == pattern[j]:
            j += 1
            lps[i] = j
            i += 1
        else:
            if j != 0:
                j = lps[j - 1]
            else:
                lps[i] = 0
                i += 1
    return lps


def kmp_search(text, pattern):
    lps = build_lps(pattern)
    i = j = 0
    while i < len(text):
        if text[i] == pattern[j]:
            i += 1
            j += 1

        if j == len(pattern):
            print("Pattern found at index", i - j)
            j = lps[j - 1]
        elif i < len(text) and text[i] != pattern[j]:
            if j != 0:
                j = lps[j - 1]
            else:
                i += 1


# Example
text = "ababcabcabababd"
pattern = "ababd"
kmp_search(text, pattern)

3. Rabin-Karp Algorithm

Idea:

Rabin-Karp uses string hashing to find patterns quickly. Instead of comparing every character, it first compares the hash values of the pattern and the current window of text. Only when hashes match do we verify the actual string.

Time Complexity:

  • Average: O(n + m)
  • Worst case: O(n × m) (rare, when there are many hash collisions)

Python Implementation:

def rabin_karp(text, pattern):
    n, m = len(text), len(pattern)
    if m == 0:
        return

    p_hash = hash(pattern)   # Python's built-in hash (for simplicity)

    for i in range(n - m + 1):
        window = text[i:i + m]
        if hash(window) == p_hash and window == pattern:
            print("Pattern found at index", i)


# Example
text = "abracadabra"
pattern = "abra"
rabin_karp(text, pattern)

Note: In competitive coding, we usually implement rolling hash manually instead of using Python’s built-in hash() for better control.

4. Longest Common Subsequence (LCS)

Idea:

Given two strings, find the length of the longest subsequence present in both strings (characters must appear in the same order, but not necessarily consecutively).

Example:

s1 = "abcde", s2 = "ace" → LCS = "ace" (length 3)

DP Approach:

def lcs(s1, s2):
    n, m = len(s1), len(s2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = 1 + dp[i-1][j-1]
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])

    return dp[n][m]


print(lcs("abcde", "ace"))  # Output: 3

Time Complexity: O(n × m)

5. Edit Distance (Levenshtein Distance)

Idea:

Find the minimum number of operations (Insert, Delete, or Replace) required to convert one string into another.

Example:

word1 = "horse"

word2 = "ros"

Answer = 3 (replace 'h'→'r', delete 'e', delete 's' wait — actually optimal is 3 operations)

Python Implementation:

def edit_distance(s1, s2):
    n, m = len(s1), len(s2)
    dp = [[0] * (m + 1) for _ in range(n + 1)]

    for i in range(n + 1):
        dp[i][0] = i
    for j in range(m + 1):
        dp[0][j] = j

    for i in range(1, n + 1):
        for j in range(1, m + 1):
            if s1[i-1] == s2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i][j-1],      # insert
                                   dp[i-1][j],      # delete
                                   dp[i-1][j-1])    # replace

    return dp[n][m]


print(edit_distance("horse", "ros"))  # Output: 3

Time Complexity: O(n × m)
