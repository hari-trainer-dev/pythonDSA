Hash

1. Hash Table

A hash table is one of the most powerful and commonly used data structures. It stores key-value pairs and gives us average O(1) time complexity for the three most important operations:

  • Insert (adding a new pair)
  • Search (finding a value by key)
  • Delete (removing a pair)

It achieves this speed by combining two things:

  • An array (for actual storage)
  • A hash function (to quickly calculate where to store or find the data)

1.2. How a Hash Table Looks Internally

Let’s imagine we create a hash table with a size of 5.

Index:   0      1      2      3      4
        --------------------------------
Value:  None   None   None   None   None

At the beginning, all slots are empty.

3. The Hash Function

The hash function is the heart of a hash table. Its job is to take any key and convert it into a valid array index (a number between 0 and size-1).

3.1 Hash Function for Integers

def hash_function(key, size):
    return key % size

Examples:

  • 10 % 5 = 0
  • 15 % 5 = 0 (Collision happens here)
  • 23 % 5 = 3

3.2 Hash Function for Strings

def string_hash(key, size):
    hash_value = 0
    for char in key:
        hash_value += ord(char)
    return hash_value % size

Example with "app":

  • a → 97
  • p → 112
  • p → 112

Total = 321

321 % 5 = 1

So "app" would go to index 1.

4. Collision

A collision occurs when two different keys produce the same hash index.

Example:

  • 10 % 5 = 0
  • 15 % 5 = 0 ← Collision!

Even though 10 and 15 are different keys, they both want to go to index 0.

5. Collision Handling Techniques

There are two popular ways to handle collisions:

5.1 Chaining (Separate Chaining)

Instead of storing a single value at each index, we store a list (also called a bucket or chain) at every index. When a collision happens, we simply append the new item to that list.

Step-by-Step Visualization:

  1. Insert (10, "Apple")

    → hash(10) = 0

    Index 0: [(10, "Apple")]
  1. Insert (15, "Banana")

    → hash(15) = 0 (collision)

    Index 0: [(10, "Apple"), (15, "Banana")]
  1. Insert (20, "Mango")

    → hash(20) = 0 (collision)

    Index 0: [(10, "Apple"), (15, "Banana"), (20, "Mango")]

Python Implementation - Hash Table with Chaining:

class HashTableChaining:
    def __init__(self, size):
        self.size = size
        self.table = [[] for _ in range(size)]

    def hash_function(self, key):
        if isinstance(key, int):
            return key % self.size

        # Simple string hashing
        hash_value = 0
        for char in key:
            hash_value += ord(char)
        return hash_value % self.size

    def insert(self, key, value):
        index = self.hash_function(key)
        self.table[index].append((key, value))

    def search(self, key):
        index = self.hash_function(key)
        for k, v in self.table[index]:
            if k == key:
                return v
        return "Not Found"

    def display(self):
        for i, bucket in enumerate(self.table):
            print(f"Index {i}: {bucket}")

Let’s Test It:

ht = HashTableChaining(5)

ht.insert(10, "Apple")
ht.insert(15, "Banana")
ht.insert(20, "Mango")
ht.insert("apple", 100)
ht.insert("banana", 200)

print(ht.search(15))      # Output: Banana
print(ht.search("banana")) # Output: 200

ht.display()

5.2 Open Addressing (Linear Probing)

In this method, we don’t use lists. If the calculated index is already occupied, we keep checking the next index (linearly) until we find an empty slot.

Step-by-Step Visualization:

  1. Insert (10, "Apple")

    → hash(10) = 0

    [ (10, "Apple"), None, None, None, None ]
  1. Insert (15, "Banana")

    → hash(15) = 0 (occupied)

    → check index 1 (empty)

    [ (10, "Apple"), (15, "Banana"), None, None, None ]
  1. Insert (20, "Mango")

    → hash(20) = 0 (occupied)

    → index 1 occupied → index 2 empty

    [ (10, "Apple"), (15, "Banana"), (20, "Mango"), None, None ]

Python Implementation - Hash Table with Linear Probing:

class HashTableOpenAddressing:
    def __init__(self, size):
        self.size = size
        self.table = [None] * size

    def hash_function(self, key):
        return key % self.size

    def insert(self, key, value):
        index = self.hash_function(key)

        while self.table[index] is not None:
            index = (index + 1) % self.size   # Linear probing

        self.table[index] = (key, value)

    def search(self, key):
        index = self.hash_function(key)
        start = index

        while self.table[index] is not None:
            if self.table[index][0] == key:
                return self.table[index][1]

            index = (index + 1) % self.size
            if index == start:
                break

        return "Not Found"

    def display(self):
        for i, item in enumerate(self.table):
            print(f"Index {i}: {item}")

Let’s Test It:

ht = HashTableOpenAddressing(5)

ht.insert(10, "Apple")
ht.insert(15, "Banana")
ht.insert(20, "Mango")

print(ht.search(20))   # Output: Mango
ht.display()
